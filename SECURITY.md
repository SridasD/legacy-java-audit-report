# Security Policy

## Sensitive audit information

This website can expose internal source paths, implementation details, and code fragments. Keep the GitHub repository private when required and configure deployment protection in Vercel.

Do not place credentials, tokens, private keys, production connection strings, personal information, or confidential database values in the report.

## Reporting a concern

Report security or privacy concerns privately to the repository owner. Do not open a public issue containing sensitive evidence.

Include the affected page or finding number, a concise description, the minimum reproduction evidence, and the recommended containment action if known.
